# Raspberry Pi 24-E 三子棋游戏装置

这是我在 2024 年大学生电子设计竞赛 E 题“三子棋游戏装置”中编写的树莓派视觉与决策代码。

项目使用 OpenCV 识别棋盘上的黑白棋子，通过 Minimax 算法计算机器下一步，并使用串口向下位机发送棋子的起点和目标位置。下位机及机械结构代码未包含在本仓库中。

## 功能

- 摄像头采集并识别 3×3 三子棋棋盘
- 手动选择棋子和目标位置
- Minimax + Alpha-Beta 剪枝计算下一步
- 检测棋子被移动，并发送复原指令
- 通过树莓派串口与运动控制下位机通信

## 通信协议

树莓派通过 `/dev/ttyAMA0` 与下位机通信，波特率为 `115200`。

```text
发送帧：0xDD + 源位置 + 目标位置 + 0xEE
下位机应答：0xAA
```

位置编号：

- `1~9`：棋盘方格
- `10~14`：黑棋存放位置
- `15~19`：白棋存放位置

## 运行环境

- Raspberry Pi
- Python 3
- OpenCV
- NumPy
- pySerial
- USB 摄像头
- 配套运动控制下位机

安装 Python 依赖：

```bash
pip install numpy opencv-python pyserial
```

运行示例：

```bash
python3 "(4).py"
```

程序依赖固定的摄像头位置、裁剪区域和棋盘坐标，实际运行前需要根据设备调整图像裁剪范围、识别阈值和串口配置。
